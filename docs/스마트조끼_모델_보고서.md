# 스마트안전조끼 착용 판정 모델 보고서

삼표피앤씨 아파트 재건축 현장 안전관제 · 2026-09-29

---

## 1. 모델 구성

| 항목 | 내용 |
|---|---|
| 백본 | DINOv3 ViT-B/16 (`facebook/dinov3-vitb16-pretrain-lvd1689m`), 86M 파라미터, **가중치 고정** |
| 입력 | 사람 크롭 112×224 RGB, ImageNet 정규화 |
| 특징 | CLS 토큰(768) + 패치 토큰 평균(768) = 1,536차원 |
| 헤드 | Linear 1536→512 · GELU · Dropout 0.2 · Linear 512→1 · Sigmoid |
| 출력 | P(스마트조끼 착용), 0.5 이상이면 착용(O) |
| 산출물 | `__MODEL__/smart_vest_260929.pt` (3.1MB, 헤드 가중치만) |

백본은 학습하지 않고 특징 추출기로만 사용했습니다. 배포 시 DINOv3 백본(약 350MB)을 함께 올리고 그 위에 이 헤드를 얹습니다.

DINOv3는 Meta의 공개 사전학습 모델로, 라이선스상 상업적 사용이 가능하며 **"Built with DINOv3" 표기 의무**가 있습니다.

## 2. 학습 환경

| 항목 | 내용 |
|---|---|
| GPU | NVIDIA RTX 2080 SUPER 8GB |
| 프레임워크 | PyTorch 2.6 (CUDA 12.4), transformers 5.17 |
| 손실 | BCEWithLogitsLoss, 클래스 불균형 보정(pos_weight) |
| 최적화 | AdamW, lr 1e-3, weight decay 1e-4, batch 256 |
| 종료 조건 | 최대 120 epoch, 검증 F1 기준 early stopping (patience 20) |
| 학습 시간 | 특징 추출 약 3분(19,473장) + 헤드 학습 1분 미만 |

## 3. 데이터 구성

### 3.1 수집

| 단계 | 결과 |
|---|---|
| 원본 영상 | 현장 CCTV 4개 (1920×1080 / 2560×1440), 총 1시간 48분 |
| 프레임 샘플링 | 1초당 1프레임 → 6,473 프레임 |
| 사람 검출 | YOLO26m 파인튜닝(`sampyo_v1.pt`), conf ≥ 0.5, 박스 넓이 ≥ 1,000px², 패딩 15% |
| 크롭 | 19,654장 → 육안 검수 후 **19,473장** (오검출 181장 제외) |

### 3.2 라벨링

근접 중복 제거를 거쳐 라벨링 작업량을 줄였습니다. DINOv3 특징의 코사인 유사도 0.90 이상이며 시간 간격 30초 이내인 크롭을 한 묶음으로 보고(같은 작업자가 연속 프레임에 잡힌 경우), 묶음 대표 1장만 사람이 판정한 뒤 묶음 전체에 전파했습니다.

| 항목 | 수량 |
|---|---|
| 전체 크롭 | 19,473장 |
| 근접 중복 묶음 | 8,523개 |
| 사람이 직접 판정한 묶음 | **7,392개** (착용 2,506 / 미착용 4,812 / 판단불가 77) |
| 라벨이 부여된 이미지 | 18,342장 (전체의 94.2%) |

### 3.3 학습에 사용한 표본

| 구분 | 수량 |
|---|---|
| 학습 | 5,323 묶음 + 조도 증강 21,292행 = **26,615행** |
| 검증 | 1,995 묶음 (현장 영상 중 학습 미사용 구간) |

**조도 증강**: 야외 주간 작업이라 동일한 주황 조끼가 햇빛·노출에 따라 노랑이나 연두로 찍힙니다. 이를 학습에 반영하기 위해 각 학습 크롭에 밝기·대비·채도·색상 지터와 좌우 반전을 적용한 사본 4장을 추가했습니다.

## 4. 검증 방법

검증은 **실제 현장 영상(2026-09-10 카메라1, 60분)만** 사용했습니다. 나머지 3개 영상(2026-09-16 촬영분)은 담당자가 직접 장비를 착용하고 카메라 앞에서 촬영한 테스트 영상이므로 검증 대상에서 제외했습니다.

현장 영상을 120초 단위 구간으로 나눠 25%를 검증 전용으로 분리하고, 해당 구간은 학습에 일절 사용하지 않았습니다. 이미지 단위 무작위 분리는 1초 간격 연속 프레임이 학습과 검증에 함께 들어가 성능이 부풀려지므로 사용하지 않았습니다.

## 5. 성능

**현장 영상 미학습 구간 1,995장 기준**

| 지표 | 값 |
|---|---|
| 정확도 | **0.950** |
| 미착용 재현율 | **0.948** (미착용 1,531건 중 1,451건 검출) |
| 미착용 정밀도 | **0.986** (미착용 판정 1,471건 중 1,451건 적중) |
| F1 | 0.967 |

미착용 오판(착용자를 미착용으로 판정)은 1,995건 중 20건으로 1.0%입니다.

**크롭 크기별 정확도**

| 사람 크롭 높이 | 장수 | 정확도 | 미착용 재현율 |
|---|---|---|---|
| 80px 미만 | 403 | 0.963 | 0.974 |
| 80~120px | 1,381 | 0.945 | 0.935 |
| 120~200px | 210 | 0.957 | 0.970 |

**카메라 교차 검증** (해당 카메라를 학습에서 완전히 제외 후 평가)

| 카메라 | 정확도 |
|---|---|
| 2026-09-16 카메라2 | 0.949 |
| 2026-09-16 카메라1 | 0.888 |

**처리 속도** (RTX 2080 SUPER): 분류기 644 crops/s (1.6ms/크롭). 사람 검출을 포함한 전체 파이프라인은 1920×1080 영상 400프레임을 40초에 처리해 **초당 약 10프레임**입니다(모델 로딩 시간 포함, 프레임당 평균 7명 검출 기준).

## 6. 운영 방법

```
현장 영상 → YOLO26m(sampyo_v1.pt) 사람 검출 → 박스 크롭(패딩 15%)
         → DINOv3 특징 추출 → smart_vest_260929.pt 판정 → 착용/미착용
```

실행: `python scripts/infer_vest.py --video <영상> --out <결과영상>`

판정 임계값은 0.5가 기본이며, 미착용을 더 적극적으로 잡으려면 낮추고 오알람을 줄이려면 높입니다.

실행 예시 영상: `docs/smart_vest_demo.mp4` (현장 영상 10초, 판정 임계값 0.8, 초록 = 착용 / 빨강 = 미착용), 확대본 `docs/smart_vest_demo_zoom.mp4`

## 7. 제약 사항

- **알람 적용 범위**: 스마트안전조끼는 트럭 적재함 위 작업자에게 의무이므로, 전체 인원이 아니라 `stair_check.py`의 트럭 위 판정과 결합해 적용해야 합니다.
- **프레임 단위 판정**: 현재는 프레임마다 독립 판정합니다. 실제 알람에는 트래킹 ID별 다중 프레임 투표를 적용해야 오알람이 줄어듭니다.
- **카메라 의존성**: 학습에 쓰지 않은 카메라에서 정확도가 0.888~0.949로 낮아집니다. 신규 카메라 설치 시 해당 화각의 데이터를 일부 라벨링해 재학습하는 것을 권장합니다.
- **안전모 판정 미포함**: 현장 작업자는 전원 안전모를 착용해 미착용 사례가 테스트 촬영분에만 존재합니다. 학습 시 모델이 안전모가 아니라 해당 카메라의 배경을 학습해 사용할 수 없는 수준이었고, 현장 재촬영 전까지 보류합니다. 조끼 판정과 헤드가 분리된 구조라 조끼 모델 단독 운용에는 영향이 없습니다.
